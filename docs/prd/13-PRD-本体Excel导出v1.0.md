# 本体 Excel 导出 v1.0 · 产品需求文档

| 项目 | 内容 |
|---|---|
| 模块 | 本体中心 → 本体工作台 → Excel 导出 |
| 版本 | v1.0，2026-10-29 |
| 状态 | 原型已实现 |

## 1. 目标

为当前本体提供可交付、可追溯的多 Sheet Excel 导出能力，兼容企业本体建模模板的使用方式。v1.0 只提供完整本体导出，导出内容来自当前工作状态。

## 2. 入口和交互

### 2.1 完整本体导出

入口放在“本体工作台”顶部命令区，按钮名称为“导出 Excel”。点击后打开“导出本体 Excel”弹窗，说明导出范围，并提供“导出完整本体”按钮。

完整导出生成一个 `.xlsx` 文件，每类资源单独一个 Sheet。当前已标准化或有数据的资源都会被导出；空资源不强行生成空 Sheet。导出会保留本体名称、命名空间、导出时间和稳定标识。

### 2.2 不在每个资源页面重复放完整导出

完整本体导出集中放在本体工作台和本体切换弹窗，避免用户在动作、规则、对象等页面重复寻找同一个全量出口。

## 3. Sheet 设计

完整导出按当前资源生成以下 Sheet：

| Sheet | 内容 |
|---|---|
| 00_本体信息 | 本体名称、命名空间、本体 ID、导出时间、说明 |
| 00_前置 | 业务域 |
| 01_业务场景 | 业务场景及对象、关系、规则、动作引用 |
| 02_对象类型 | 对象类型、对象标识、分类、定义、业务域、状态 |
| 03_对象属性 | 属性编码、名称、类型、必填、约束及所属对象 |
| 04_关系 | 关系两端、方向、基数、说明 |
| 05_对象实例 | 实例标识、所属对象、业务主键、状态、来源系统 |
| 06_数据源映射 | 目标属性、数据源、表、字段、更新频率 |
| 07_规则 | 规则标识、类型、适用对象、逻辑、输出、触发动作 |
| 08_动作 | 动作标识、名称、作用对象、触发规则、触发条件、输出 |
| 09_动作映射 | 动作、执行系统、接口能力、执行方式 |
| 11_系统 | 数据源/公司系统资源 |
| 13_接口能力 | 系统接口能力及输入输出 |
| 14_权限安全 | 主体、资源、权限、数据范围、审批和有效期 |
| 17_证据来源 | 模型元素的来源、原始证据、识别结论、置信度和审核状态 |

模板中存在但当前没有可导出规范化数据的 Sheet 不生成空表；模板原始行仍通过现有 JSON 数据包和资源元数据保留，后续可扩展为“原始模板行”附加 Sheet。

## 4. 文件命名规范

v1.0 所有 Excel 导出文件统一使用以下格式：

```text
{本体名称}_本体全量导出_{YYYYMMDD_HHmmss}.xlsx
```

- 例如：`共享运营业务量预测与资源调度本体_本体全量导出_20261030_154500.xlsx`。
- 文件名使用本体中文名称，不使用命名空间。
- 时间统一使用 UTC，格式为 `YYYYMMDD_HHmmss`，便于排序、检索和跨时区协作。
- 本体名称中的文件系统保留字符替换为下划线，连续空白压缩为单个下划线。
- 浏览器响应同时提供兼容文件名 `ontology-export.xlsx` 和 UTF-8 `filename*`，确保中文环境与不同浏览器都能正常下载。

## 5. 数据规则

- 使用当前本体工作状态，不要求先发布版本。
- 对象、关系、动作、规则等稳定 ID优先使用业务 external_id/code；没有业务 ID时使用内部 ID。
- 资源之间的关联字段同时导出 ID和名称，避免只导出不可读的 UUID。
- 列表、字典和 JSON 结构序列化为 UTF-8 文本；布尔值使用“是/否”。
- Sheet 首行是字段表头，冻结首行并启用筛选；长文本自动换行。
- 导出失败时返回明确错误，不生成空文件。

## 6. 接口

- `GET /api/ontologies/{ontology_id}/export.xlsx`：导出完整本体 Excel。
- 原有 `GET /api/ontologies/{ontology_id}/export` JSON 导出保持兼容。

## 7. 验收标准

- 本体工作台可以打开导出弹窗并下载完整 `.xlsx`。
- 完整导出至少包含当前有数据的所有核心资源 Sheet。
- v1.0 导出文件使用中文本体名称，不包含命名空间。
- 导出文件可以被 Excel/WPS 正常打开，字段表头、中文内容、筛选和冻结首行正常。
- 导出不修改当前本体、不创建变更记录。
- 当前附件类多 Sheet 工作簿中的对象、关系、规则、动作、动作映射、接口能力、权限安全等资源可以在对应 Sheet 中找到。
