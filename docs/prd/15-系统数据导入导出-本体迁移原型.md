# 系统数据导入导出：本体迁移原型

状态：交互原型，待评审。系统菜单的“系统数据导出／导入”提供演示，演示清单不是实际迁移包。

## 导出

- “本体与数据源”作为同一个导出子菜单，宽屏页面左右两列分别选择本体和数据源，窄屏上下排列；两列各自搜索和滚动。按本体整体多选，包含每个本体的语义资源及其内部引用；共享数据源按需手选，默认不选。
- 本体中的数据映射等保留数据源引用；未携带的来源不能默认为已绑定，应在导入预检中提示并允许用户匹配目标环境的来源或保留待处理状态。
- 数据源拟导出登记信息及已采集的表结构快照，不导出业务数据、账号、密码、令牌或其他凭据；结构信息是否包含敏感标识须由目标环境权限控制。
- 当前原型只能按各本体读取数据源，并非全局共享目录；同名或同编码项不自动合并，选择时显示来源本体。

## 导入

1. 上传迁移包，展示包中本体、数据源及引用依赖，分别选择。
2. 本体和数据源冲突统一提供“覆盖、跳过、追加”：覆盖将包内对应内容替换到目标资源；跳过保留目标资源；追加只补充不存在的子资源、属性或结构项，遇到同标识项保留目标值，不自动覆盖。正式实现需明确冲突颗粒度、依赖处理和跨资源引用重映射。
3. 导入前检查缺失依赖、冲突决策、结构版本及权限；未解决的依赖和不可执行项目明确列出。
4. 新建数据源导入后标记“待配置凭据／待验证”，数据源菜单显示红色提醒，列表展示待处理项；填写目标环境账号密码并通过连接测试后解除标记。覆盖或追加已有数据源时，保留目标环境原有凭据；覆盖影响连接的配置后应重新校验，追加未更改连接配置时保留现有连接状态。
5. 展示逐项成功、跳过、失败和待处理结果；不能将部分成功标成全部成功。

## 原型范围

- 支持多本体勾选、数据源独立勾选、搜索、清单下载与上传、示例清单、选择和冲突处理，以及模拟导入后的数据源菜单红点和提示。
- 下载的 JSON 只包含所选名称和标识，不含语义资源、表结构或连接配置，不是可用于生产迁移的文件。
- 模拟导入仅在当前浏览器会话记录提示，不写数据库，不创建本体／数据源，不接收真实迁移包，也不验证连接；跳转的数据源页不会出现新建的模拟记录。
- 依赖分析、全局共享数据源、完整迁移包、引用重映射、凭据持久化、连接验证及跨环境权限控制均需后续研发实现。
