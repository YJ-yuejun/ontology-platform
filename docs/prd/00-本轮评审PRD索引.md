## 3. 本轮最关键的产品决策

1. **产品层不再把“发布版本”作为对比入口**：比较对象是两个本体；副本用于迭代和备份，发布版本退为底层实现细节。
2. **编号采用 6 位规则**：`3 位本体族编号 + 3 位副本序号`，复制递增末三位，手动新建分配新族号。
3. **对比页采用“总览 → 差异目录 → 单条差异 → 字段/关联 → AI”五层结构**。
4. **展示层可提示“疑似改名/重建”，但不改写算法输出的严重级**；确认改名必须由人完成。
5. **AI 只解释差异，不修改本体、不重算严重级、不推断生产运行影响**。
6. **对象属性仍归属于对象类型**；新增属性是对象编辑的快捷入口，不是独立资源。
7. **本体智能页采用单列对话 + 抽屉**，避免“菜单 + 本体菜单 + 历史列表 + 对话”四列并存。
8. **数据映射直连物理字段**，治理资产不再作为映射必经层。

## 4. 原型状态与限制

| 模块 | 原型状态 | 限制 |
|---|---|---|
| 本体对比工作台 | 前端可交互，使用 A/B mock 数据 | 尚未接后端真实 A/B 对比接口 |
| 编号与副本 | 前端演示编号规则 | 后端尚无 `ontology_number` 字段和编号分配器 |
| 对比 AI | 本地规则解读 | 尚未接真实模型或 `compare-with/chat` |
| 对象属性新增 | 前后端可用 | 并发编辑未做版本锁 |
| 本体智能 | 前后端可用 | 历史会话按当前本体隔离；AI 仍为演示/降级 |
| 数据映射直连 | 前后端可用，含 mock 数据 | 连接器与真实同步任务未实现 |
| 对象探索与对象视图 | 前后端可用，含对象集/图表/预览/标准对象视图 | 保存探索目前本地；Compare/Pivot/Configured Object View 待补 |
| 数据源 / 数据映射 / 映射图谱 | 前后端可用；已拆为独立菜单与页面 | 批量确认/推荐/真实同步/字段级血缘待补 |
| 本体智能 | 资源选择/只读问答/历史/浮窗/图谱问 AI 可用 | 停止重试、提案确认、写操作审计待落地 |

## 5. 统一验收前提

- 所有页面在 1366 / 1722 宽度下不出现横向溢出。
- 不新增“版本选择”入口；只允许出现“基线 / 副本 / 备份”语义。
- 所有 AI 入口必须明确标注“只读解读”，不得出现“自动合并”“自动修复”文案。
- 对比页的算法原始严重级、形态、字段值必须可追溯，不得被展示层静默改写。
