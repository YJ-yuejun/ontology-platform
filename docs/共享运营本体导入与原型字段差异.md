## 优先调整建议

1. 动作页增加规则关联及“审批待确认”，规则页展示触发行动；支持由 ID 选择并可追溯双向引用。
2. 对象实例支持缺项草稿和补全提示；属性页补充长度、值域/约束；业务域与主题域分开建模。
3. 统一导入时的 ID 引用、范围解析与未匹配提示；场景允许输出缺失时保存草稿。
4. 数据映射、系统能力和权限页区分描述性登记与已验证/已生效配置。
