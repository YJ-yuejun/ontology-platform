# 对象类型保存失败（状态属性）问题定位与修复

## 现象

编辑对象类型时保存被拒，提示 **"状态属性必须来自已定义的属性字段"**；而「状态属性」下拉框看起来是空的/显示"未指定"，用户完全看不出哪里不对。管道运输运营本体里 **客户、管线、管段、站场** 4 个对象必现。

## 根因：导入时的一处错误兜底

`backend/enterprise.py` 导入 `02_对象类型` 时：

```python
state_property=property_key_by_name.get(raw["状态属性"], "status")
```

模板的「状态属性」列写的是**中文属性名**（客户状态 / 合同状态 / 运行状态 …），而 `property_key_by_name` 这张映射表只覆盖了其中一部分。**映射失败时它硬回落成字面量 `"status"`**，于是：

| 对象 | 模板「状态属性」 | 对象实际属性 | 被写入的 state_property | 结果 |
|---|---|---|---|---|
| 合同 | 合同状态 | contractId, **status** | status | ✅ 有效 |
| 设备 | 设备状态 | **status**, … | status | ✅ 有效 |
| 工单 | 工单状态 | …, **status** | status | ✅ 有效 |
| 告警 | 告警状态 | …, **status** | status | ✅ 有效（名字不匹配但属性存在） |
| 运输任务 | 任务状态 | …, **status** | status | ✅ 有效 |
| **客户** | 客户状态 | customerId, customerName | status | ❌ **引用了不存在的属性** |
| **管线** | 运行状态 | pipelineId, pipelineName | status | ❌ |
| **管段** | 运行状态 | pressure, pressureRate, segmentId | status | ❌ |
| **站场** | 运行状态 | stationId, stationName | status | ❌ |

前端保存前会校验，4 个失效引用正是被这条挡住：

```js
if (form.state_property && !keys.has(form.state_property)) return '状态属性必须来自已定义的属性字段。';
```

**为什么用户看不出原因**：步骤 2 的状态属性下拉只列出「标注为状态属性 / 枚举类型」的属性，这 4 个对象一个都没有，所以下拉没有能匹配 `status` 的选项，浏览器就把首项"未指定"显示出来了——**界面显示的值和表单真实持有的值不一致**，于是"看着没问题却存不了"。

## 三层修复

### 1. 导入侧：不再凭空造 `status`

`backend/enterprise.py` 新增 `_resolve_state_property()`，解析顺序：

1. 按**属性显示名**匹配对象自己的属性；
2. 查映射表，且**确认该属性确实存在**；
3. 只有在对象**确实有 `status` 属性**时才回落到 `status`；
4. 否则明确留空（`None`）。

对上面 9 个对象的解析结果：合同/设备/工单/告警/运输任务 → `status`（合理），客户/管线/管段/站场 → 空（正确）。

### 2. 历史数据：幂等自愈

`backend/repository.py` 新增 `repair_object_state_property()`，在 `init_db()` 中随其它 repair 一起执行：凡是 `metadata.state_property` 指向的属性已不存在，一律清空为"未指定"。

- 幂等，每次启动都跑，属性以后被删也能自愈；
- **不丢证据**：模板原值仍保留在 `metadata.template_raw["状态属性"]`（实测 `客户状态`、`运行状态` 都还在）。

### 3. 前端：让失效值不可能再"隐形"挡住保存

`frontend/src/pages/ObjectTypes.jsx`：

- `startEdit` 先把失效的 `title_property` / `state_property` 按当前属性重置，**不再让历史脏值把用户挡在保存之外**；
- 步骤 2 给出可读解释，例如：
  > 模板记录的状态属性是「客户状态」，但对象属性里没有对应字段，因此未设置状态属性；可以在下方选择一项，或先到"属性定义"补上该属性。
- 下拉框增加兜底选项：当持有值不在可选列表里时，把它**显式显示出来**（区分"当前值未标注为状态属性"与"原值属性已不存在"），而不是静默显示成"未指定"。
