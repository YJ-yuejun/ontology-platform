# 对话式本体建模原型（2026-09-22，入口融合版）

## 本轮实现范围

沿用现有平台导航、模板字段和本体数据。新增本地 `/chat` 页面，复现“智能问答 + 本体建模助手”交互；该路由不是线上问答系统地址。

- 撤下独立“智能构建”菜单和任务大厅。旧 `/ontology/build` 链接自动回到本体工作台；对话历史仍在智能问答中。
- `/chat`：新建、完善、检查三类任务入口；问答历史可收起。
- 新建本体：填写名称、命名空间和业务说明 → 下一步选择智能构建或手动建模 → 确认后才真正创建本体。返回上一步保留输入，取消不创建空本体。
- 选择智能方式时，刚创建的真实本体 ID 和业务说明自动带入对话，不再填写一遍，也不再创建第二个本体；此时本体容器已保存，但智能建议仍是演示数据。
- 选择手动方式时，进入带下一步提示的工作台：按现有内容引导建立业务域、主题域、对象，之后按需补关系、规则和动作，不强迫填满所有模块。
- 工作台“新建资源”：选资源类型与智能/手动方式。对象、关系、规则、动作、接口页面的新建按钮共用选择方式；明确选择手动后直接开现有表单。
- 工作台“更新本体”和对象页“更新选中对象”：可选择智能增量建议或手动编辑；更新本体还可继续同一本体的最近建模对话。
- 输入框预置 `@本体建模助手`，能力标签显示 `/ontology-creator`。跳转不自动发送。
- 对话引导确认目标与范围；新建任务补本体名称、命名空间和业务说明；局部任务指定已有对象。
- 右侧按需打开定义、差异、依据；修改候选字段后重新确认。
- 接受、暂缓、保存演示草稿、下载、继续下一轮、恢复任务；历史演示草稿保留。
- 原有六步构建流程仅保留 `/ontology/build/legacy` 兼容访问，不在主导航展示；原有任务及治理页面保留。

## 真实与演示的边界

| 内容 | 本轮行为 |
|---|---|
| 本体、对象与属性 | 从已有后端读取真实定义 |
| 智能体调用 | 尚未连接线上对话智能体，不调用 DeepSeek 或其他 LLM |
| 附件 | 只登记文件名与大小；不上传、解析或将内容作为证据 |
| 候选变更 | 明示的内置对象/属性示例，不是自然语言或附件抽取结果 |
| 模型检查 | 对真实对象执行主键数量、对象/属性标识重名、标题属性引用检查；不是完整语义校验 |
| 保存 | localStorage 中的演示草稿；不写入真实本体或发布版本 |
| 并发检测 | 保存前重新读取目标对象，比较定义；演示级检查，不是后端事务保证 |
| 业务行动执行 | 不包含 |

任务记录仅在相同浏览器、相同 origin 下可恢复，不等同于服务端会话。切换 localhost / IP / 端口不会共享本地记录。文件内容未持久化；真实接入时必须上传并绑定正式资料 ID。浏览器存储被禁用、空间不足或记录损坏时显式报错，不显示保存成功。

## 与研发真实能力对接

现有对话智能体可以继续保留，但不把每个智能体固定绑定为一个前端步骤。

1. 由统一会话服务持久化 task_id、conversation_id、ontology_id、working_copy_id、base_revision、资源范围、evidence_ids、候选修订号。命令文本不充当目标绑定或授权依据。
2. 专业智能体返回结构化事件：需要补充信息、候选资源/变更、冲突、校验结果、错误与完成。前端按卡片类型展示，不根据智能体名称另造页面。
3. 候选内容包含稳定资源 ID、操作、before/after、来源定位、影响范围。字段映射采用原模板，不增加业务字段。
4. 接受建议不等于入库、评审通过或发布。真实保存需要服务端权限校验、引用校验、修订号比较和幂等事务；不能照搬本轮 localStorage 演示保存。
5. 设计中可提交确认写入；待评审/评审通过修改前需按权限退回设计中并作废原批准；已发布模型需明确派生或复用工作副本，正式快照不覆盖。
6. 模型实际提议超出修改范围时重新征求确认；读取相关依赖不意味着可以修改依赖。
7. 真实附件接入后才显示解析进度与证据，失败需可重试；不将附件中的指令作为用户命令执行。

## 演示验收路径

1. 本体目录 → 新建本体 → 填写信息 → 下一步 → 智能构建 → 创建并进入绑定当前本体的对话；不重复填写本体信息。
2. 同一流程选择手动建模 → 按工作台下一步提示建立业务分类及对象；取消或上一步不应创建额外本体。
3. 新建资源 → 关系类型 → 手动：缺少对象时给出前置步骤和直达按钮；已有对象时直接打开关系表单。智能则带上“关系类型”范围，不用对象示例冒充关系结果。
4. 更新本体 → 选择资源范围与方式；选中对象更新则直接定位该对象。智能问答检查模式仍可只读检查。
5. 刷新或从更新本体／智能问答历史打开原任务；确认草稿、附件登记、对话和目标没有丢失。
6. 修改已接受候选字段，确认恢复待确认；重复标识、缺少名称和空枚举应阻止接受。
7. 切换任务不混用本体/对象；开始下一轮，上一轮消息和演示草稿可继续查看。
8. 窄屏打开详情时使用单一详情视图，关闭回到原对话，不叠加永久多栏。

验证命令：前端 `npm test`、`npm run build`；后端隔离测试 `./.venv/bin/python -m unittest discover -s tests -v`。本轮不使用截图或电脑操控校验。
